ABOUT THE PROJECT

AI Integrated MFC Battery System

This project proposes an intelligent energy storage architecture that integrates a Microbial Fuel Cell, battery storage, ESP32-based sensing and artificial intelligence.

The ESP32 collects system parameters such as battery voltage and temperature. These parameters are processed by a machine-learning model to estimate future battery behavior and support intelligent energy management.

⚠️
Prototype Simulation Notice

The current prototype uses a simulated MFC voltage input because the physical MFC generation module is not yet available. The simulated input is clearly identified throughout the dashboard and will be replaced with real MFC measurements in the final system.
